# 使用指南

**简体中文** | [English](USAGE.en.md)

## 第一次使用

部署者先按 [自行部署指南](SELF_HOSTING.md) 启动服务，再把可访问的网址发给伙伴。每个人都在**同一个网址**注册自己的账号，不需要下载或安装项目。没有默认管理员、默认密码或预置实验账号。

打开网页后点击「登录 / 注册」。注册时填写昵称、邮箱和至少 8 位密码。当前邮箱用于登录和添加好友，不发送验证邮件，也没有邮件找回密码功能，请自行记住密码。不同部署的账号互不通用。

## 建立一个项目并邀请伙伴

1. 在主页的「工作区」下点击「创建工作区」，填写项目名称。
2. 点击该工作区，右侧就是文件库，可以上传文件、创建文件夹。
3. 在「群聊」下点击「创建群聊」，选中刚才的工作区，并选择群聊可见范围。
4. 群主在聊天右上角打开「查看成员 → 邀请加入本群」，生成邀请链接并发给伙伴。对方在同一个服务地址注册或登录，查看授权范围后点击「确认加入」。

生成邀请时使用伙伴能打开的局域网地址或正式网站地址。`127.0.0.1` 只表示正在使用浏览器的那台电脑，发给别人不能让他们连接你的电脑。

工作区保存共享项目资料，群聊保存讨论。多个群聊关联同一个工作区时，看到的是**同一个工作区文件库**。群邀请也会授予关联工作区文件及公开群聊的访问权限，请先确认这些资料适合分享给受邀者。其他私有群聊仍需单独邀请。

## 聊天和好友

- 主页点击群聊，在右侧输入消息；Enter 发送，Shift+Enter 换行。
- 点击左侧「好友」，通过对方在该部署注册的邮箱添加；对方接受后即可私聊。
- 消息支持回复、代码块、@ 提醒、收藏和置顶。群主可移除群成员；私聊右上角可删除好友。
- 右上角「查找记录」按关键词、日期和消息/文件筛选。文件关键词查文件名，不搜索文件正文。
- 聊天需要服务在线。发送失败请按提示重试；关机、断网时不支持离线发送。

## 文件放在哪里、谁能看

| 操作位置 | 可访问的人 |
| --- | --- |
| 主页工作区、文件页的团队共享 | 该工作区的全部成员 |
| 关联工作区的群聊上传时选择「添加到工作区文件库」 | 工作区全部成员，其他关联群也能在工作区看到 |
| 群聊上传时选择「仅保存到本群附件库」 | 当前群成员 |
| 独立群聊附件 | 当前群成员 |
| 好友私聊附件 | 当前好友关系的双方 |
| 文件页「我的文件工作区」 | 当前账号 |

这些是网站的访问权限；实际文件内容统一保存在部署机器的数据库中，部署者有能力读取数据库。它们不会自动保存到每个成员的硬盘或同步到 GitHub。

群聊右上角「本群附件」查看仅本群文件；「查找记录」中的文件范围还可切换到「工作区文件库」或「本群聊天中的全部附件」。消息搜索始终限当前聊天。

同名上传可以保留两份，例如 `说明.md` 与 `说明 (2).md`；也可以更新原文件并保留旧版本。文件行「…」可重命名、移动、查看版本或移入回收站。单文件最大 10 MB，UTF-8 文本预览最大 1 MB；其他文件下载后用本机软件打开。

## 下次使用与数据保存

普通成员重新打开原来的网址并登录即可。部署者需保持机器开机、联网且服务运行；关机后大家不能继续使用，重新启动原服务后可继续访问已保存的数据。关闭普通成员的浏览器不会关闭服务器。

默认数据为部署目录的 `data/workspace.db`，备份在 `data/backups/`；Docker 使用持久化命名卷。个人文件、附件、版本和聊天都包含在数据库里。迁移、备份、恢复和升级的方法见 [自行部署指南](SELF_HOSTING.md)。不要删除数据目录，也不要用另一份空部署代替原部署后期待旧账号自动出现。

当前没有多人同时编辑、在线运行代码和 Git 同步。上传源码可以保存、预览和下载，不会执行源码。
